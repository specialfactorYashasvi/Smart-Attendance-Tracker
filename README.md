# Smart Attendance & Eligibility Tracker

A Python-based command-line tool to track academic attendance, calculate eligibility based on customizable thresholds (default 75%), and provide strategic advice on how many lectures you can miss or need to attend to meet your goals.

## Features
* Add multiple subjects with custom attendance thresholds.
* Mark attendance (Present/Absent).
* View a comprehensive dashboard with attended/total lectures, percentages, and strategic advice.
* Export attendance reports to CSV.

## Tech Stack
* Python 3
* SQLite3
* CSV

## Usage
The script uses only built-in standard Python libraries, so no `requirements.txt` installation is needed.

To run the tracker:
`python main.py`
